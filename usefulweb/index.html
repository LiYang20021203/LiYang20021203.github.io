推荐使用顺序

根据网络环境和文件类型选择工具，会比盲目尝试更省时间。

Recommended Workflow

Choose tools based on network access and file type. It saves time compared with random trial and error.

1. 先判断任务类型

只是压缩、合并、拆分或格式转换，优先用 I Love PDF；需要读懂英文 PDF，再进入翻译工具。

2. 没有 VPN 先用 BabelDOC

免 VPN 更省心，但免费频率有限。遇到频率限制时，可以换账号或等一段时间再试。

3. 有 VPN 且量大用 PDF2ZH

连续翻译多份 PDF 时更适合 PDF2ZH。若页面打不开，先检查代理是否真的生效。

1. Identify the task first

For compression, merge, split, or conversion, start with I Love PDF. For understanding English PDFs, move to translation tools.

2. No VPN: try BabelDOC first

It is easier when VPN is unavailable, but the free tier has frequency limits. Switch accounts or wait before retrying.

3. With VPN and high volume: use PDF2ZH

PDF2ZH is better for translating many PDFs in a row. If the page does not load, check whether the proxy is working.
