# 课题组人格测评

一个纯静态的趣味人格测评网页，围绕组会情况、实验情况、出勤情况、薪资情况和组内协作展开。

## 发布目标

```text
LiYang20021203/LiYang20021203.github.io
```

目标位置：

```text
gh-pages/useless/index.html
```

访问地址：

```text
https://liyang20021203.github.io/useless/
```

## 文件

- `index.html`：单文件版网页，已经内嵌 CSS 和 JavaScript，上传这一个文件即可访问。
- `styles.css`：拆分版样式，保留给后续维护。
- `script.js`：拆分版题目、计分和结果逻辑，保留给后续维护。

直接用浏览器打开 `index.html` 即可。

## 手动上传

1. 打开 `https://github.com/LiYang20021203/LiYang20021203.github.io/tree/gh-pages/useless`。
2. 点击 `Add file` -> `Create new file` 或 `Upload files`。
3. 上传或粘贴本目录下的 `index.html`。
4. 文件路径保持为 `useless/index.html`，提交到 `gh-pages` 分支。
5. 等待 GitHub Pages 刷新后访问 `https://liyang20021203.github.io/useless/`。

如果想后续继续维护拆分版，也可以一并上传：

```text
styles.css
script.js
```
